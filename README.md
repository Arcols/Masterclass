# Masterclass

All the code should be written in English.

## Git Conventions

### Branching

Each branch should be named with a descriptive name, the prefix should be BT or BF (Besoin Technique / Besoin Fonctionnel), then the number of the issue and a short description.

_Exemple :_ 
`BT-12.3-AddANewFunction`

### Commits
The commit should be done on the branch.
Each commit should be named with a descriptive name. It will start with a key word (feat/fix/refactor/etc) then a description of the commit.

_Exemple :_ 
`feat: Add of the new function`

## Coding Conventions

All the variables should be declared with a type.

You should not return an Object type if it is not necessary.

Each function should have a descriptive name.

## Naming Conventions

### Functions

Functions should be written in PascalCase.

_Exemple :_ 
`function MyFunction() :`

Functions will have clear and descriptive names.

### Variables

Variables should be written in camelCase.

_Exemple :_ 
`var myVariable :`

Variables will have clear and descriptive names.

### Constants

Constants should be written in UPPER_CASE.

_Exemple :_ 
`const MY_CONSTANT :`

Constants will have clear and descriptive names.
