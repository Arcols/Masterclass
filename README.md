# Masterclass

All the code should be written in English.

## Coding Conventions

All the variables should be declared with a type.

You should not return an Object type if it is not necessary.

## Naming Conventions

### Functions

Functions should be written in PascalCase.

_Exemple :_ 
`function MyFunction() :`

Functions will have clear and descriptive names.

### Variables

Variables should be written in camelCase.

_Exemple :_ 
`var myVariable :`

Variables will have clear and descriptive names.

### Constants

Constants should be written in UPPER_CASE.

_Exemple :_ 
`const MY_CONSTANT :`

Constants will have clear and descriptive names.
